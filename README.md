# Gaussian Processes for Computing Option Greeks

Companion code for the report **"Gaussian processes and the computation of Greeks"** (Bouke Hoekstra & Bruno Fernandez, June 2026). The full write-up is at [`docs/Gaussian_Processes_and_the_Computation_of_Greeks.pdf`](docs/Gaussian_Processes_and_the_Computation_of_Greeks.pdf). The report extends the GP option-pricing examples in Dixon, Halperin & Bilokon (2020) in three directions: a broader kernel comparison with all five Greeks, automatic differentiation for the second-order and cross Greeks, and scalable GP training via KISS-GP.

## What's in this repo

Every script maps to a section of the report:

| Script | Report section | What it does |
|---|---|---|
| `src/section_4_1_kernel_comparison.py` | **§4.1** | Fits six kernels (RBF, Matérn-3/2, Matérn-5/2, Rational Quadratic, RBF+Linear, RBF+Matérn) to Black-Scholes call prices and computes all five Greeks (Δ, Γ, ν, Θ, ρ). Analytic kernel derivatives for RBF and Matérn-5/2, central finite differences on the GP mean for the composite kernels. Reproduces the paper's Table 1 (price accuracy) and Table 2 (per-Greek RMSE). |
| `src/section_4_2_bs_autograd.py` | **§4.2.1–3** | 2-D GP surrogate on the Black-Scholes surface (S, σ), Matérn-5/2 ARD kernel, 15×15 = 225 training points on [60,140]×[0.1,0.5]. Extracts Δ, Γ, ν and the cross-Greek **Vanna** via `torch.autograd.grad` with no manual mixed-derivative formulas. Reproduces the paper's Table 3 including the interior-relative-error metric. |
| `src/section_4_2_heston_autograd.py` | **§4.2.4** | Same autograd approach on Heston prices generated by the Fang–Oosterlee COS pricer. Reproduces book Fig 3.6 (n=50/100/150 training points) and pulls Δ and ν with **95% credible bands** propagated from the GP posterior covariance — the closed-form hedging-risk margin from the report's abstract. |
| `src/section_4_2_heston_surfaces.py` | **§4.2.4** | Book Fig 3.3 reproduction: 3 maturities T−t ∈ {1.0, 0.5, 0.1} × {call, put}, 30×30 training grid → 40×40 out-of-sample test grid. Uses the vectorised COS pricer. |
| `src/section_4_3_kissgp_scaling.py` | **§4.3** | Exact GP vs KISS-GP timing sweep up to n = 2·10⁵. Verifies the near-linear scaling of KISS-GP against the O(n³) reference of the exact GP. |
| `figs/make_3d_bs_figures.py` | §4.2 (alt viz) | Same 2-D BS autograd model as §4.2.1–3 but rendered as 3-D surfaces with the analytical truth overlaid as a wireframe. Optional presentation figure. |
| `docs/gp_from_scratch_demo.py` | §3 companion | Pure-numpy GP class (Cholesky + L-BFGS-B hyperparameter optimisation) with hand-coded kernel derivatives. Recovers Δ, Γ, ν on a 1-D Black-Scholes call. Exists to make the maths transparent — not to reproduce paper tables. |

## Pricing modules

Both experiments and helpers live under `src/pricers/`:

| Module | What's inside |
|---|---|
| `src/pricers/black_scholes.py` | `bsformula(cp_flag, S, K, r, T, sigma, q)` returning `(price, delta, vega, gamma, theta, rho)`. Compatible with the book's `BlackScholes` import convention used by the Section 4.1 script. |
| `src/pricers/heston_cos.py` | Fang–Oosterlee COS method (Little-trap CF). Scalar `heston_call_cos`, vectorised `heston_call_cos_vec` and `heston_put_cos_vec` (put priced directly, not via parity, for short-maturity stability). Runs with `python -m src.pricers.heston_cos` to reproduce the built-in validation suite (BS-limit check, monotonicity, scalar-vs-vectorised, N-convergence). |

## Running

```bash
pip install -r requirements.txt

# Section 4.1 — 6-kernel comparison, all 5 Greeks
python src/section_4_1_kernel_comparison.py

# Section 4.2 — Black-Scholes 2-D surrogate + Vanna
python src/section_4_2_bs_autograd.py

# Section 4.2.4 — Heston autograd Greeks with credible bands
python src/section_4_2_heston_autograd.py

# Section 4.2.4 — Heston call/put surfaces at 3 maturities
python src/section_4_2_heston_surfaces.py

# Section 4.3 — KISS-GP scalability benchmark
python src/section_4_3_kissgp_scaling.py
```

All figures are written to `./output/` (which is gitignored). Console output includes the summary tables reported in the paper.

## Model parameters (as in the report)

- **§4.1 Black-Scholes**: K = 130, r = 0.002, σ = 0.4, T = 2, n = 100 training points on rescaled [0, 1].
- **§4.2 Black-Scholes 2-D**: K = 100, r = 0.02, T = 1, (S, σ) ∈ [60, 140] × [0.1, 0.5], 15×15 = 225 training points, Matérn-5/2 ARD, 200 Adam iterations, 50×50 test grid.
- **§4.2.4 Heston**: κ = 0.1, θ = 0.15, σ (vol-of-vol) = 0.1, ρ = −0.9, r = 0.002, K = 100, V₀ = 0.1 (book Table 3.1/3.2).
- **§4.3 KISS-GP**: 1-D BS calls on S ∈ [1, 200], grid_size = 400 inducing points, sweep n ∈ {500, 1k, 2k, 5k, 10k, 15k, 20k, 200k}. Exact-GP capped at n = 17,000.
